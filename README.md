> **From Farm to Market — Every Batch. Every Checkpoint. Every Payment. Verified.**

FarmChain AI is a next-generation agricultural supply-chain platform that combines **AI-powered quality assessment, blockchain-inspired traceability, IoT cold-chain monitoring, QR-based provenance, and smart-contract escrow** into a single platform.

The goal is simple: **give farmers better transparency, buyers greater trust, logistics teams real-time visibility, and consumers proof of where their food came from.**

---

## 🚀 Why FarmChain AI?

Traditional agricultural supply chains often suffer from:

* ❌ Lack of transparency between farmers, logistics providers and buyers
* ❌ Difficulty verifying product quality
* ❌ Limited visibility during transportation
* ❌ Manual and delayed payment processes
* ❌ No easy way for consumers to verify product origin
* ❌ Data manipulation and fragmented records

### 💡 Our Solution

FarmChain AI creates a **digital identity for every agricultural batch**.

From the moment a farmer registers a harvest until the product reaches the buyer:

**Harvest → AI Quality Check → Blockchain Record → IoT Monitoring → Delivery Verification → Escrow Payment → Consumer QR Verification**

Every important event becomes part of a traceable digital journey.

# ✨ Key Features

## 🌾 1. Farmer Harvest Registry

Farmers can register agricultural batches with important information such as:

* Batch ID
* Crop information
* Harvest details
* Farmer information
* Location
* Quality information
* Supply-chain checkpoints

Each batch receives a unique identity that can be tracked throughout its journey.

## 🤖 2. AI-Powered Crop Quality Assessment

FarmChain AI integrates an AI quality-assessment workflow to evaluate agricultural produce.

The system can assess factors such as:

* 🍎 Ripeness
* 🎨 Color distribution
* 🔍 Surface blemishes
* ⭐ Overall quality
* 💰 Suggested price premium

This helps reduce subjective/manual quality assessment and enables more transparent pricing.

### AI Workflow

```text
Crop Image
    ↓
AI Quality Analysis
    ↓
Quality Grade
    ↓
Defect Detection
    ↓
Price Premium Recommendation
    ↓
Quality Certificate
```

---

## ⛓️ 3. Blockchain-Based Traceability

Each batch follows a verifiable chain of supply-chain events.

Important milestones can include:

```text
HARVEST
   ↓
QUALITY VERIFIED
   ↓
PACKED
   ↓
DISPATCHED
   ↓
IN TRANSIT
   ↓
DELIVERED
```

The architecture includes blockchain-style records, cryptographic hashes and Merkle-root concepts to make the provenance history easier to verify.

This creates a **tamper-evident supply-chain history**.

---

## 🚚 4. IoT Cold-Chain Monitoring

Transportation conditions can directly affect agricultural quality.

FarmChain AI provides telemetry monitoring for:

* 🌡️ Temperature
* 💧 Humidity
* 📳 Shock / vibration
* 🚨 Threshold violations

When abnormal conditions occur, the system can generate breach alerts.

### Example

```text
IoT Sensor
    ↓
Telemetry Gateway
    ↓
Temperature / Humidity / Shock
    ↓
Threshold Analysis
    ↓
Normal ─────────→ Continue Shipment
    │
    └───────────→ 🚨 Breach Alert
```

This gives logistics teams visibility into the condition of produce during transportation.

---

# 🔐 5. Smart-Contract Escrow

FarmChain AI introduces an escrow-based payment workflow.

Instead of relying entirely on manual payment coordination:

```text
Buyer
  ↓
Funds Locked in Escrow
  ↓
Product Dispatched
  ↓
Delivery Verified
  ↓
Conditions Satisfied
  ↓
💰 Payment Released to Farmer
```

This can reduce payment disputes and improve trust between farmers and buyers.

# 📱 6. QR-Based Consumer Verification

A consumer can scan the QR code to access the batch's provenance information.

```text
     ↓
🚚 Logistics History

⛓️ Supply Chain Timeline

✅ Verified Product
```

This transforms supply-chain transparency from a backend feature into a **consumer-facing experience**.

# ⚡ Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/aryansingh173-cyber/FarmChain-AI.git

cd FarmChain-AI
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Configure Environment Variables

Create a `.env.local` file based on `.env.example`.

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

> ⚠️ Never commit `.env.local` or real API keys to GitHub.

## 4. Configure Supabase

Open your Supabase project's SQL Editor and execute:

```text
supabase/schema.sql
```

This creates the required database structure.

## 5. Start the Development Server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
